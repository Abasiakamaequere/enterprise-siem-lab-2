# Deployment

This directory documents the deployment of the SIEM infrastructure.

## Current Platform

* VirtualBox
* Ubuntu Server 25.04
* Splunk Enterprise 10.4.2

## Deployment Stages

1. VirtualBox VM provisioning
2. Ubuntu Server installation
3. Network configuration
4. Splunk Enterprise installation
5. Package troubleshooting
6. Filesystem recovery
7. Privilege separation
8. Splunk initialization
9. Splunk Web verification

Detailed deployment documentation will be maintained in this directory.
